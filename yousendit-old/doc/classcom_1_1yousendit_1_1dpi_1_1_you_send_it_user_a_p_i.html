Calls the "Create new user" REST API method. Since this REST method does not require authentication (authToken), it was declared as a static method, and the endpoint information has to be passed in the parameters.

       Synopsis         Create new user
       HTTP Method      POST
       HTTP Header      X-Api-Key
       URL              <EndPoint>/dpi/v1/user

Description:

  • Created user account is a YouSendIt Lite account, which is a free account. Check the link http://www.yousendit.com/compare-plans to see the storage limits and maximum upload size for the Lite users.
  • User is sent an email with an activation link that they must click to activate their account before they can use the account
Parameters:
emailRequired Parameter: The email address of the new user. Maximum 128 characters are allowed in the email address.
passwordRequired Parameter: The password for the new user. Minimum 5 characters are required for the password.
firstnameOptional Parameter: The first name of the user. Maximum 128 characters are allowed in the first name.
lastnameOptional Parameter: The last name of the user. Maximum 128 characters are allowed in the last name
apiEndpointRequired Parameter: Developer API endpoint to send requests to, e.g. https://api.yousendit.com
apiKeyRequired Parameter: Developer API key used to authenticate the developer
Returns:
The User object reflecting the status of the operation
