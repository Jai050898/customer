File com.yousendit.dpi.YouSendItFileTransferAPI.downloadFile ( String  downloadURL,
String  downloadFolder,
String  password 
) throws DPIException, Exception

Downloads a file from YouSendIt. If the password parameter is specified (not null), it will consider the file to be password protected, and it will send the password parameter. If the file already exists, then it's overwritten with the downloaded file.

       Synopsis         Download a file or resume file download
       HTTP Method      GET
       HTTP Headers     X-Api-Key, X-Auth-Token
       URL              The URL obtained from /dpi/v1/item/<itemId>  or /dpi/v1/folder/file/<fileId>

Description:

  • This call can be used to download a file programmatically.
  • Only those file can be downloaded, that are available to the user whose authToken is being used in this call.
  • The URL to use for calling this API is a downloadUrl obtained from /dpi/v1/item/<itemId> or /dpi/v1/file/<fileId> APIs. This URL doesn’t contain the hostname (i.e. http://dpi.yousendit.com (for production, after approval) or http://test2-api.yousendit.com (for sandbox). You have to prepend that part in order to call this API. Note that this downloadUrl can’t be used within a browser to download files as it’s a URL for the API. The downloadUrl response returns an HTTP 302 redirect to the real download location of the file.
  • The HTTP Range header is only used to resume a download in the event of an interruption. The Range header is defined in the HTTP spec (RFC 2616). In most cases it would be “bytes=<offset>-“, where offset is the byte to start the download from. (to resume a download used the resumeDownload(String, String, String, String) method)
Parameters:
downloadURLRequired Parameter: Download URL is obtained from Items or ItemInfo API.
downloadFolderRequired Parameter: Folder to download the file to. This folder must exist or an exception is thrown.
passwordOptional Parameter: Password for the file.
Returns:
File object for the downloaded file.
Exceptions:
DPIExceptionIf download fails, a DPIException is thrown which contains the error message, HTTP status code, and HTTP status message.
ExceptionIf an unexpected low-level exception occurs.

Resumes a download file from YouSendIt. If the password parameter is specified (not null), it will consider the file to be password protected, and it will send the password parameter.

       Synopsis         Download a file or resume file download
       HTTP Method      GET
       HTTP Headers     X-Api-Key, X-Auth-Token
       URL              The URL obtained from /dpi/v1/item/<itemId>  or /dpi/v1/folder/file/<fileId>

Description:

  • This call can be used to download a file programmatically.
  • Only those file can be downloaded, that are available to the user whose authToken is being used in this call.
  • The URL to use for calling this API is a downloadUrl obtained from /dpi/v1/item/<itemId> or /dpi/v1/file/<fileId> APIs. This URL doesn’t contain the hostname (i.e. http://dpi.yousendit.com (for production, after approval) or http://test2-api.yousendit.com (for sandbox). You have to prepend that part in order to call this API. Note that this downloadUrl can’t be used within a browser to download files as it’s a URL for the API. The downloadUrl response returns an HTTP 302 redirect to the real download location of the file.
  • The HTTP Range header is only used to resume a download in the event of an interruption. The Range header is defined in the HTTP spec (RFC 2616). In most cases it would be “bytes=<offset>-“, where offset is the byte to start the download from. (The range header is set automatically, based on the size of the partially downloaded file)

Uploads a file to the YouSendIt servers.

       Synopsis         Upload a file
       HTTP Method      POST
       URL              uploadURL from /dpi/v1/item/send or /dpi/v1/file/initUpload
       Content-Type     multipart/form-data; boundary=<desired boundary>="">

Description:

  • Uploading a file to YouSendIt requires that you interact directly with YouSendIt’s storage servers. The identifier for the file being uploaded and the URL of which storage server to use are obtained from /dpi/v1/item/send (itemId and uploadUrl respectively) or /dpi/v1/file/initUpload (fileId and uploadUrl respectively).
Parameters:

uploadURLRequired Parameter: uploadURL from /dpi/v1/item/send or /dpi/v1/file/initUpload
fileToUploadRequired Parameter: The name (absolute or relative location) of the file to be uploaded.
