Resume the Download of a File

Parameters:
urld- required - The download URL.
dir- required - The download folder (path+folderName).
password- optional - If a password has been set, the recipients are asked to enter the password before they can access the files. The minimum length of the password is 5 characters.
range- optional - Only the specified range of bytes is downloaded and appended to the existing file if a range has been set. If no range has been set the entire file is downloaded and saved inside the download directory (the value from $dir).
Returns:
The status "fail" if the download has failed or the downloaded file name if the download has succeeded.
