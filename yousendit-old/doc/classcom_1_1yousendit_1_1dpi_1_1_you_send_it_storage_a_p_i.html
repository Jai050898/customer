Implements the "Commit file upload to a folder" REST API method. Finalizes the upload of a file to a YouSendIt folder. 

       Synopsis         Commit file upload to a folder
       HTTP Method      POST
       HTTP Headers     X-Api-Key, X-Auth-Token
       URL              <EndPoint>/dpi/v1/folder/file/commitUpload

Description:

  • User needs write permission to the folder where the file needs to be saved.
  • This API must be called after uploading the files in order for the upload to be successfully completed.
Parameters:
nameRequired Parameter: name of the uploaded file
fileIdRequired Parameter: The id of the file returned by /dpi/v1/folder/file/initUpload
parentIdOptional Parameter: The id of the folder, where the file will be saved. A value of 0 indicates root folder. Default value: 0 - root folder.
Returns:
A File object, representing the uploaded file.
Exceptions:

) throws DPIException, DPIErrorStatus

Calls the "Move Folder" Rest API method.

       Synopsis         Move the folder to some other folder
       HTTP Method      PUT
       HTTP Headers     X-Api-Key, X-Auth-Token
       URL              <EndPoint>/dpi/v1/folder/<folderId>/move

Description:

  • Root folder cannot be moved
  • If a user moves a folder that has been shared with the user (even in view mode), the folder can be moved only to a folder which is not already shared
  • If a user moves a folder that has been shared with the user (even in view mode), the folder moves only for this user and not for the owner or other members
  • User needs write permissions on the shared folder to move a sub folder from the shared folder
  • The move fails if a folder with the same name already exists at the new location
Parameters:
folderIdRequired Parameter: ID of the folder to move.
parentIdRequired Parameter: The folder ID where user wants to move the folder
