) throws DPIErrorStatus, DPIException

Calls the "Change expiration of an item in user’s Sent Items" REST API method.

       Synopsis         Change expiration of an item in Sent Items
       HTTP Method      POST
       HTTP Headers     X-Api-Key, X-Auth-Token
       URL              <EndPoint>/dpi/v1/item/expiration/<itemId>

Description:

  • The ability to set expiration depends on the underlying account associated with this user. LITE users cannot change file expiration.
  • Expiration cannot be changed for the Inbox items.
  • itemId is part of the URL and is obtained from the /dpi/v1/item/<itemId>
  • Note: An itemId obtained from /dpi/v1/item/send isn’t valid for expiration API until after a successful commit (/dpi/v1/item/commit/<itemId>).
Parameters:
itemIdRequired Parameter: The ID of the item in question.
expirationRequired Parameter: The expiration duration in minutes. A value of 0 indicates that the file never expires.
Returns:
An Expiration object with expiration date as status
Exceptions:
DPIExceptionIf method fails, a DPIException is thrown which contains the error message, HTTP status code, and HTTP status message.
DPIErrorStatusIn case the Server responds with an error status. The exception contains the status code and the message

       Synopsis         Delete an item from Inbox or Sent Items or cancel pending item upload
       HTTP Method      DELETE
       HTTP Headers     X-Api-Key, X-Auth-Token
       URL              <EndPoint>/dpi/v1/item/<itemId>

Item com.yousendit.dpi.YouSendItSendReceiveAPI.getItemInfo ( String  itemId) throws DPIException, DPIErrorStatus

Calls the "Get item info" REST API method

       Synopsis         Get item info for an item in Inbox or Sent Items
       HTTP Method      GET
       HTTP Headers     X-Api-Key, X-Auth-Token
       URL              <EndPoint>/dpi/v1/item/<itemId>

Description:

  • Use this API to get detailed information about an item including password protection, return receipt and verify recipient identity.
  • itemId is part of the URL and is obtained from the /dpi/v1/item/list or /dpi/v1/item/send web services.
  • Note: An itemId obtained from /dpi/v1/item/send isn’t valid for getting the item info until after a successful commit (/dpi/v1/item/commit/<itemId>).
  • The API returns the tracking element in the XML response only if tracking info is available for the item. Tracking is not available if the user is a LITE user or if user in looking at the Inbox items.
Parameters:
itemIdRequired Parameter: The ID of the item in question.
Returns:
An Item object with details like itemId, expiration date, file details etc.

Calls the "Get upload URL for a new item" REST API method.

       Synopsis         Get upload URL for a new item
       HTTP Method      POST
       HTTP Header      X-Api-Key, X-Auth-Token
       URL              <EndPoint>/dpi/v1/item/send

Description:

  • Use this call to initiate the upload process
  • The ability to upload more than one file depends on the underlying account associated with this user.
  • Verify Recipient Identity, Return Receipt, and Password are options which may or may not be available depending on the underlying account associated with this user.
  • For corporate users, this API honors the policies set by account administrators.
Parameters:
recipientsRequired Parameter: Comma separated email addresses of the recipients. Maximum 300 email addresses can be provided. The maximum length of an email address is 128 characters.
filesOptional Parameter: The number of files to be sent. Maximum 20 files can be sent at a time.
subjectOptional Parameter: The subject for the email notification. Maximum 200 characters are allowed in the subject.
messageOptional Parameter: The message for the email body. Maximum 2000 characters are allowed in the message
verifyIdentityOptional Parameter:If true, the recipients are required to login to access the files.
returnReceiptOptional Parameter: If true, an email notification is sent to the sender, when someone downloads the file.
passwordOptional Parameter: If set, the recipients are asked to enter the password before they can access the files. The minimum length of the password is 5 characters.
Returns:
An Send object with upload URLs.
Exceptions:
DPIExceptionIf method fails, a DPIException is thrown which contains the error message, HTTP status code, and HTTP status message.
DPIErrorStatusIn case the Server responds with an error status. The exception contains the status code and the message
