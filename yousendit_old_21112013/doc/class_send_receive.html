Get Upload Urls

Parameters:
recipients- required - Comma separated email addresses of the recipients. Maximum 300 email addresses can be provided. The maximum length of an email address is 128 characters.
filecount- optional - The number of files to be sent. Maximum 20 files can be sent at a time.
subject- optional - The subject for the email notification. Maximum 200 characters are allowed in the subject.
message- optional - The message for the email body. Maximum 2000 characters are allowed in the message.
verifyIdentity- optional - If true, the recipients are required to login to access the files.
returnReceipt- optional - If true, an email notification is sent to the sender, when someone downloads the file.
password- optional - If set, the recipients are asked to enter the password before they can access the files. The minimum length of the password is 5 characters.
Returns:
An Upload object with upload URLs or the error code and message thrown by the server.
