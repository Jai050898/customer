AuthWrapper com.yousendit.dpi.YouSendItAuthAPI.login ( String  email,
String  password 
) throws DPIException, DPIErrorStatus

Calls the "Get authentication token" REST API method.

       Synopsis         Get an authentication token, to be used in all other calls
       HTTP Method      POST
       HTTP Header      X-Api-Key
       URL              https://test2-api.yousendit.com/dpi/v1/auth

Description:

  • Use this API to login the user. Almost all API calls require the authentication token returned by this call.

Usage: This methods returns an AuthWrapper instance, which contains the result of the actual authorization call in an Auth object, and a RestTransport instance. The RestTransport instance encapsulates the endpoint information and the authentication token, and can be used to initialize the other classes that implement the YouSendIt REST API methods.

Parameters:
emailRequired Parameter: The email address of the user
passwordRequired Parameter: The password of the user
Returns:
The user authentication token encapsulated in an Auth object.
Exceptions:
DPIExceptionIf method fails, a DPIException is thrown which contains the error message, HTTP status code, and HTTP status message.
DPIErrorStatusIn case the Server responds with an error status. The exception contains the status code and the message
